Nichtlinearer Einmassenschwinger

Gleicher EMS, aber mit begrenztem Widerstand Fy = Fel / Ry (bilinear, kinematische Verfestigung). Vergleich mit der elastischen Antwort und Duktilitätsbedarf μ = umax / uy.

Theorie und Methode

Was die App rechnet. Alle Grössen sind auf die Masse bezogen (m = 1); Kräfte werden erst für die Anzeige mit m multipliziert.

Bewegungsgleichung des EMS

m·ü + c·u̇ + k·u = −m·ag(t)(1)
ω = 2π / T,   k = m·ω²,   c = 2·ζ·m·ω(2)
u: Relativverschiebung, ü: Relativbeschleunigung, aabs = ü + ag: Absolutbeschleunigung

Newmark, konstante mittlere Beschleunigung (β = 1/4, γ = 1/2), inkrementelle Formulierung

meq = m + c·γ·h + k·β·h²(3)
Δu* = h·u̇i + h²/2·üi,   Δu̇* = h·üi(4)
Δü = (−c·Δu̇* − k·Δu* − m·Δag) / meq(5)
üi+1 = üi + Δü,   u̇i+1 = u̇i + Δu̇* + γ·h·Δü,   ui+1 = ui + Δu* + β·h²·Δü(6)

Das Verfahren ist unbedingt stabil, aber nur genau, wenn der Rechenschritt h klein gegenüber T ist. Die App unterteilt deshalb jeden Schritt Δt des Zeitverlaufs in n = ⌈50·Δt / T⌉ Teilschritte (h ≤ T/50) und interpoliert ag linear. Startwerte: u = u̇ = 0, ü0 = −ag,0 (Gleichgewicht bei t = 0). Spitzenwerte werden in jedem Teilschritt gesucht, nicht nur zu den Zeitpunkten der Aufzeichnung. Kontrolle gegen exakte Lösung (Zustandsraum, linear interpolierte Anregung): Abweichung der Spektralwerte < 0,5 %, auch bei grob abgetasteten Zeitverläufen (Δt = 0,04 s). Eigene Zeitverläufe: Ein ungleichmässiges Zeitraster wird linear auf das mittlere Δt interpoliert; Einheit (m/s², g, cm/s²) und bei einspaltigen Dateien Δt sind in der Seitenleiste wählbar. Interpolation ersetzt keinen fehlenden Frequenzinhalt: Bei Δt > 0,02 s sind Spektralwerte unter T ≈ 5·Δt nicht aussagekräftig und werden grau hinterlegt.

Ausschwingphase: Jeder Zeitverlauf wird intern um max(5 s, 5·T) (höchstens 50 s) mit ag = 0 verlängert. Spitzenwerte, die erst nach Ende der Anregung auftreten, werden so erfasst, und der EMS kommt annähernd zur Ruhe. Die bleibende Verschiebung des nichtlinearen EMS ist die Mittellage der letzten vollen Schwingung (Mittel aus Maximum und Minimum über eine Periode T) und damit unabhängig vom restlichen Ausschwingen.

Antwortspektrum

VerschiebungSd(T, ζ) = max |u(t)|(7)
GeschwindigkeitSv(T, ζ) = max |u̇(t)|,   Pseudo: PSv = ω·Sd(8)
BeschleunigungSa(T, ζ) = max |aabs(t)|,   Pseudo: PSa = ω²·Sd ≈ Sa für ζ ≤ 20 %(9)
ErsatzkraftF = k·Sd = m·PSa(10)

Periodenraster: 240 logarithmisch verteilte Werte von 0,01 s bis 10 s. Grenzwerte: T → 0 ergibt Sa → PGA (starrer EMS), T → ∞ ergibt Sd → max |Bodenverschiebung|.

Nichtlinearer EMS (bilinear, kinematische Verfestigung)

Fy = Fel / R = k·Sd(T) / R,   uy = Fy / k(11)
α·k·u − (1−α)·Fy ≤ F(u) ≤ α·k·u + (1−α)·Fy(12)
μ = umax / uy,   gleiche Verschiebungen: μ ≈ R,   gleiche Energie: μ ≈ (R² + 1) / 2(13)

Newmark (β = 1/4, γ = 1/2) in Gesamtform mit Newton-Raphson-Iteration je Teilschritt (Chopra, Dynamics of Structures, Kap. 5.7). Die Federkraft wird je Iteration aus dem letzten konvergierten Zustand bestimmt (elastischer Prädiktor, Rückprojektion auf die Fliessgrenzen). Dämpfung c bezogen auf die Anfangssteifigkeit. α = 0: elastisch-ideal plastisch.

Inelastisches Spektrum für gegebenes Ry

Fy(T) = Fel(T) / Ry = m·ω²·Sd(T) / Ry(14)
Sa,inel(T) = max |aabs,inel(t)|,   Sv,inel = max |u̇inel|,   Sd,inel = max |uinel|(15)
Vergleich: Sa,el / Ry (Kraftreduktion) und Sd,el (gleiche Verschiebungen)(16)

Im Tab Antwortspektrum mit «inelastisch» einblenden; je Periode des Spektrums (240 Werte) eine nichtlineare Zeitverlaufsberechnung. Bei α = 0 gilt |aabs,inel| = |F + c·u̇| / m ≤ Fy/m + c·|u̇|/m: Sa,inel liegt in der Regel über Sa,el/Ry (wenn Fy erreicht wird), bei sehr kurzen Perioden deutlich, weil dort die Dämpfungskraft (c = 2ζmω gross) dominiert. Bezug zur Norm: SIA 261 reduziert die Kräfte mit q = μΔ·λ0 (VO 9, Folie 35) und setzt für die Verschiebungen das Prinzip der gleichen Verschiebungen voraus (Folie 47).
